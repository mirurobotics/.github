This lens is documentation (the document skill, if
available): whether the docs still tell the truth after this
change.
- Find READMEs, doc comments, API docs, examples, CLI help
  and skill text that describe what changed, including files
  the PR doesn't touch, and flag any that are now wrong.
- Flag new public behavior, config or flags that users or
  other agents need and that nothing documents.
- Flag comments that restate the code, state limits or timings
  another file owns, or will drift, and docs that contradict
  each other.
